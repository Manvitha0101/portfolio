# Manvitha Budidha Portfolio

A responsive personal portfolio showcasing my projects, skills, achievements, and journey as a Software Engineering student.

## Features

- Responsive design
- Dark/Light mode
- Smooth animations with Framer Motion
- Project showcase
- Skills and certifications
- Contact section
- Resume download

---

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

---

## Projects

- **SmartRoute** 
  Intelligent delivery route optimization system using Spring Boot, PostgreSQL, PostGIS, OSRM, Docker, and route optimization algorithms.

- **MediAssure**  
  Medicine adherence and health monitoring system built using Flutter and Firebase.

- **Coding Progress Tracker**  
  Tracks coding progress, problems solved, and learning analytics.
